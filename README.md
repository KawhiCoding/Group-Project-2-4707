# Bookstore Database Schema

This project is the SQL table definitions for a bookstore management system. The schema is designed to manage orders, payments, books, inventory, employees, suppliers, and customers for the project

To run the code copy/paste it into a sql test bench of your choice
Now put it into a schema side like mySQL workbench 
Input your values you want and create table will create it for you
Then you can use that info and say  SELECT * FROM Customer
WHERE LastName = 'Smith'; to get the data you want
That is it
